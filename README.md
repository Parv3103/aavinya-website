## 🚀 Running the Project Through Terminal

You can run this project from your terminal using any of the following options:

### **Option 1: Python Built-in Server (Recommended)**
Run the built-in HTTP server:
```powershell
python -m http.server 8000
```
Then open your browser and navigate to: [http://localhost:8000](http://localhost:8000)

---

### **Option 2: Node.js / npx serve**
Run using `npx serve`:
```powershell
npx serve .
```
Follow the local URL displayed in your terminal (usually `http://localhost:3000` or `http://localhost:5000`).

---

### **Option 3: Directly Open in Browser (PowerShell)**
Open `index.html` directly in your default browser:
```powershell
Start-Process index.html
```
